Set up AiversePulse demo accounts

This one-time setup creates only demo2_employee, demo2_hr, and demo2_admin. It does not replace or erase other data.

Enter the temporary DEMO_BOOTSTRAP_TOKEN you saved in Replit Secrets. Generated passwords appear here once; save them privately.

After saving the passwords, remove DEMO_BOOTSTRAP_TOKEN from Replit Secrets. The setup also refuses to run again once any of these accounts exists.
