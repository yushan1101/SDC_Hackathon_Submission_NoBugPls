# Mina (interviewer character)

- Character: **KPOP_Mina**, from [LKZMuZiLi/human](https://github.com/LKZMuZiLi/human) (`Assets/KPOP_Mina`), a Unity real-time digital human.
- Browser loading and materials adapted from HoloHuman ([OLGTX303/human-multiplatform](https://github.com/OLGTX303/human-multiplatform), `holohuman/web/src/mina.js`).
- Files here: `mina.fbx` is `SK_MINA_CASUAL_01_with_bones_in_skirt.fbx`, unchanged. The textures are the originals resized to 1024 px (eyes 512, teeth 256), with colour maps saved as JPEG and the hair and lash masks as greyscale+alpha PNG.
